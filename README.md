# Nova X Icon Store

مستودع فهرس متجر الأيقونات الخاص بتطبيق Nova X Launcher.

## رابط الفهرس

استخدم التطبيق رابط Raw التالي لقراءة قائمة الحزم:

`https://raw.githubusercontent.com/kelaniomar31-droid/NovaX-Icon-Store/main/catalog.json`

## الملفات

- `catalog.json`: قائمة الحزم وروابط تنزيلها ومعلومات التوافق والترخيص.
- `categories.json`: تصنيفات المتجر.
- `packs/`: مخصص مستقبلًا لبيانات الحزم الأصلية التي ينشئها فريق Nova X، وليس لنسخ ملفات المشاريع الخارجية دون مراجعة الترخيص.
- `previews/`: صور معاينة الحزم الأصلية أو الصور المسموح بإعادة نشرها.

## الحزم الخارجية الحالية

1. **Arcticons** — يتم التنزيل مباشرة من إصدار المشروع الرسمي. كود المشروع GPL-3.0 وأعمال الأيقونات CC BY-SA 4.0. يجب إظهار النسب للمؤلفين والالتزام بشرط المشاركة بالمثل عند إعداد أي أعمال مشتقة.
2. **Appstract** — يتم التنزيل مباشرة من إصدار المشروع الرسمي. الترخيص المعلن Apache-2.0.

لا يقوم هذا المستودع حاليًا باستضافة ملفات APK الخارجية أو إعادة توقيعها أو تعديلها. روابط التنزيل تتجه إلى إصدارات المشاريع الأصلية، ويجب أن يعرض Nova X اسم المطور والترخيص ورابط المصدر قبل التنزيل.

## متطلبات دمج المتجر في Nova X

- قراءة `catalog.json` من رابط Raw أعلاه.
- التعامل مع `downloadType: apk` كحزمة Android خارجية، وليس كملف ZIP لاستيراد الأيقونات مباشرة.
- بعد التنزيل، استخدم مُثبّت Android الرسمي، ولا تحاول تثبيت APK بصمت أو تجاوز موافقة المستخدم.
- بعد التثبيت، اكتشف حزمة الأيقونات عبر واجهة Android القياسية، واقرأ appfilter / موارد الحزمة بالطريقة المدعومة.
- تحقق من SHA-256 قبل فتح مُثبّت Android.
- اعرض المصدر والترخيص وبيانات النسب بوضوح.
- لا تحذف أو تستبدل أي ثيمات أو حزم موجودة مسبقًا في Nova X.
- احتفظ بنسخة مخبأة من الفهرس لعرض المتجر عند انقطاع الإنترنت.

## إضافة حزمة جديدة

أضف عنصرًا جديدًا داخل مصفوفة `packs` في `catalog.json` بعد التحقق من:
- أن المشروع حزمة أيقونات Android فعلية ومتوافقة.
- رابط إصدار رسمي صالح.
- اسم الحزمة (applicationId) الصحيح.
- الترخيص الدقيق للأيقونات والكود كلٌ على حدة.
- قيمة SHA-256 للملف الذي سيُنزل.
- إذن إعادة التوزيع إذا كان سيتم نسخ الملفات إلى هذا المستودع.

يفضّل ربط المستخدم بالمصدر الرسمي بدل نسخ ملفات طرف ثالث إلى هذا المستودع. وجود المشروع على GitHub لا يعني تلقائيًا أن إعادة نشر ملفاته مسموحة.
