# Nova X Icon Store

مستودع فهرس متجر الأيقونات الخاص بتطبيق Nova X Launcher.

## رابط الفهرس

`https://raw.githubusercontent.com/kelaniomar31-droid/NovaX-Icon-Store/main/catalog.json`

## الحزم الخارجية الحالية

- أكثر من 15,000 أيقونة؛ الإصدار 15.3.2 يذكر 15,322 أيقونة.
- ترخيص البرنامج: GPL-3.0.
- ترخيص الأيقونات: CC BY-SA 4.0.
- المصدر والإصدارات: https://github.com/Arcticons-Team/Arcticons
- التنزيل من الإصدار الرسمي: https://github.com/Arcticons-Team/Arcticons/releases/tag/15.3.2

- المؤلفة الأصلية للأيقونات: Melanie Gutzmann؛ المشروع الحالي fork مجتمعي.
- المصدر والإصدارات: https://github.com/yangchoo/Appstract
- التنزيل من الإصدار الرسمي: https://github.com/yangchoo/Appstract/releases/tag/v5.0.6
- ملاحظة: إصدارات GitHub موصوفة من المشروع بأنها موقعة بمفتاح debug للاختبار؛ إصدار F-Droid يُبنى ويوقّع بصورة منفصلة.

## مصادر مجانية إضافية

### Papirus Icon Pack
- أكثر من 1,500 أيقونة بحسب وصف المشروع.
- يدعم Nova Launcher وفق قائمة اللانشرات المختبرة في README الرسمي.
- الترخيص: Apache-2.0.
- المصدر الرسمي: https://github.com/PapirusDevelopmentTeam/papirus_icons
- الحالة في الكتالوج: رابط مصدر خارجي فقط؛ لم نضع رابط APK أو ZIP غير موثّق. يلزم توفير إصدار رسمي قابل للتنزيل أو دعم استيراد المصدر قبل إظهار زر تنزيل مباشر.

### Lawnicons
- حزمة مجانية مفتوحة المصدر من فريق Lawnchair ومساهمي المجتمع.
- تصميم أحادي اللون بخطوط خارجية، وتدعم معظم اللانشرات الخارجية.
- الترخيص: Apache-2.0.
- المصدر الرسمي: https://github.com/LawnchairLauncher/lawnicons
- ملفات المصدر: `svgs/`، وملف ربط التطبيقات موثق في دليل المساهمة باسم `app/assets/appfilter.xml`.
- يتضمن المشروع معالج SVG خاصًا به لتحويل ملفات SVG إلى Vector Drawables؛ لذلك لا نفترض أن ملفات المصدر جاهزة للاستخدام المباشر دون معالجة.
- الحالة في الكتالوج: مصدر خارجي فقط. لا يوجد رابط APK أو ZIP مباشر مضاف قبل التحقق منه، ولا يتم الادعاء بأن استيراده داخل Nova X أصبح مدعومًا.

## سياسة التوزيع

- الفهرس يحتوي روابط مباشرة إلى إصدارات المشاريع الأصلية؛ لا نستضيف ملفات APK الخارجية ولا نعيد توقيعها.
- لا يعني وجود مشروع على GitHub أن كل ملفاته أو أيقوناته متاحة لإعادة النشر بلا شروط.
- عند عرض الحزم، اعرض اسم المطور والترخيص ورابط المصدر.
- احترم شروط النسب والمشاركة بالمثل الخاصة بـ CC BY-SA 4.0، وشروط GPL-3.0 أو Apache-2.0 بحسب المشروع.
- تحقق من SHA-256 للملف الذي تم تنزيله، ثم استخدم واجهة تثبيت Android الرسمية التي تتطلب موافقة المستخدم.
- لا تحاول تثبيت APK بصمت أو تجاوز تحذيرات Android.

## متطلبات دمج المتجر في Nova X

- اقرأ `catalog.json` من رابط Raw أعلاه.
- اعرض الحزم الخارجية كحزم Android منفصلة؛ لا تتعامل مع APK على أنه ZIP لاستيراد الأيقونات مباشرة.
- لا تعرض مصادر `external-source-only` على أنها قابلة للتنزيل أو التطبيق المباشر.
- عند إضافة دعم الاستيراد، تحقق من ملفات المصدر ومساراتها وتنسيقاتها، وعالج SVG بأداة موثوقة مع فحوص سلامة مناسبة.
- بعد تثبيت المستخدم لحزمة APK، اكتشفها عبر واجهات Android القياسية، واقرأ appfilter وموارد الحزمة بالطريقة المدعومة.
- احتفظ بنسخة مخبأة من الفهرس لعرض آخر قائمة معروفة عند انقطاع الإنترنت.
- لا تحذف أو تستبدل أي ثيمات أو حزم أيقونات أو إعدادات موجودة مسبقًا في Nova X.

## إضافة حزمة جديدة

قبل إضافتها، تحقّق من أن المشروع حزمة أيقونات Android فعلية، ومن رابط الإصدار الرسمي واسم الحزمة وإصدارها وترخيص الأيقونات والكود كلٌ على حدة، ومن قيمة SHA-256. لا تنسخ ملفات طرف ثالث إلى هذا المستودع إلا بعد التأكد من أن الترخيص يسمح بذلك.
